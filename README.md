## Выбранный API: Rick and Morty API
**Описание**: [Rick and Morty API](https://rickandmortyapi.com/) — это RESTful API по мотивам мультсериала "Рик и Морти". Оно предоставляет информацию о сотнях персонажей, их статусе, происхождении и текущем местоположении. В приложении реализован поиск по имени и детальный просмотр каждого героя.

## Как запустить
1. Склонируйте репозиторий.
2. Откройте проект в Android Studio (Ladybug или новее).
3. Убедитесь, что установлен Android SDK 36.
4. Нажмите **Run**. API открытое, дополнительные ключи не требуются.

## Реализованный функционал
### Обязательные требования:
- [x] **Навигация**: 3 экрана (Список, Детали, Избранное).
- [x] **Архитектура**: 
    - [x] UiState (Loading, Success, Error, Empty).
    - [x] ViewModel + viewModelScope.
    - [x] Repository для работы с Retrofit.
- [x] **Coroutines + Retrofit**: Все сетевые запросы через suspend функции.
- [x] **UI состояния**: Индикатор загрузки, обработка ошибок с кнопкой Retry, экран "Ничего не найдено".
- [x] **Избранное**: Локальное хранение в ViewModel (сохраняется при повороте экрана).

### Бонусы:
- [x] **Compose + Material3**: Современный интерфейс.
- [x] **Navigation Compose**: Маршрутизация через NavHost.
- [x] **Debounce поиска**: Задержка 500мс перед запросом.
- [x] **Экран Favourites**: Отдельный роут в приложении.
- [x] **Coil**: Загрузка и кэширование изображений.
- [x] **OkHttp Logging**: Логирование сетевых запросов в Logcat.
